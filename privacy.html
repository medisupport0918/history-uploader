1. 이 도구가 하는 일 / Scope

역사 재현소 업로더(이하 "도구")는 (주)메디써포트가 회사 소유의 유튜브 채널에 자체 제작 영상을 업로드하기 위해 사용하는 사내 도구입니다. 회사 직원만 사용하며 외부에 제공하지 않습니다.

The Tool is an internal application used only by MEDISUPPORT staff to upload self-produced videos to the company's own YouTube channel.

2. YouTube API 서비스 / YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침이 함께 적용됩니다.

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google Privacy Policy: https://policies.google.com/privacy

3. 접근·사용·저장하는 정보 / Information accessed, used and stored

  • OAuth 인증 토큰: 담당자가 Google 계정으로 로그인해 허용하면 발급되는 접근 토큰과 갱신 토큰을, 업로드를 실행하는 회사 PC 안에만 저장합니다. 서버로 전송하거나 외부에 공유하지 않습니다.
  • 채널 정보: 올바른 채널에 연결됐는지 확인하기 위해 채널 이름, 채널 ID, 구독자 수, 영상 수를 조회해 화면에 표시만 하고 저장하지 않습니다.
  • 업로드 기록: 같은 영상을 중복으로 올리지 않도록 업로드한 영상 ID만 회사 PC에 기록합니다.
  • 다른 사용자의 개인정보, 시청자 정보, 댓글, 분석 데이터는 접근하거나 수집하지 않습니다.

We store only the OAuth access/refresh tokens (locally on the company computer that runs the Tool), and the IDs of videos we uploaded (to avoid duplicates). Channel title/ID/statistics are read only to confirm the connected channel and are not stored. We do not access or collect any other user's data, viewer data, comments or analytics.

4. 제3자 제공 / Sharing

수집한 정보를 제3자에게 판매하거나 제공하지 않습니다. 영상과 메타데이터는 YouTube API를 통해 YouTube(Google)에만 전송됩니다.

We do not sell or share any information with third parties. Videos and metadata are sent only to YouTube (Google) through the YouTube API.

5. 쿠키 / Cookies

이 도구와 이 웹페이지는 쿠키나 추적 기술을 사용하지 않습니다.

Neither the Tool nor this website uses cookies or similar tracking technologies.

6. 보관 기간과 삭제 / Retention and deletion

인증 토큰은 도구를 사용하는 동안만 보관합니다. 사용을 중단하거나 요청이 있으면 즉시(늦어도 7일 이내) 회사 PC에서 삭제합니다. 언제든지 Google 보안 설정 페이지에서 이 도구의 접근 권한을 철회할 수 있으며, 철회 시 토큰은 더 이상 사용할 수 없습니다.

Tokens are kept only while the Tool is in use and are deleted from the company computer upon request or when use stops (within 7 days at the latest). You can revoke the Tool's access at any time via the Google security settings page (https://security.google.com/settings/security/permissions).
