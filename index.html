무엇을 하는 도구인가요? / What it does

(주)메디써포트가 직접 제작한 역사 다큐멘터리 영상을, 회사가 운영하는 유튜브 채널 역사 재현소에 업로드하는 사내 도구입니다. 외부 사용자에게 제공하거나 판매하지 않습니다.

This tool uploads history documentary videos produced by MEDISUPPORT to the company's own YouTube channel. It is used only by our staff and is not offered or sold to third parties.

YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침이 적용됩니다.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

사용하는 기능 / API usage

  • videos.insert — 완성된 영상을 비공개(private)로 업로드 / upload finished videos as private
  • thumbnails.set — 영상 썸네일 등록 / set the video thumbnail
  • channels.list (mine=true) — 연결된 채널 확인 / confirm the connected channel

공개 여부와 공개 시점은 담당자가 YouTube 스튜디오에서 직접 확인한 뒤 정합니다. 다른 사람의 채널이나 데이터에는 접근하지 않습니다.

Publishing is always decided by a person in YouTube Studio. The tool never accesses other users' channels or data.
